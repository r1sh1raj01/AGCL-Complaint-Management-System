# AGCL Complaint Management System

Brief Description of Project: The Complaint Management System for Assam Gas Company Ltd. (AGCL) is a
web-based application designed to streamline the process of logging, tracking, and resolving complaints within the
company. The system allows employees to raise complaints, track their status, and receive notifications about
updates. Administrators or Heads of Departments (HODs) can view, assign, and track complaints, while engineers
are notified of assigned complaints and work on resolving them. This project aims to enhance communication and
efficiency in handling complaints, ensuring timely resolution and improving overall service quality.
